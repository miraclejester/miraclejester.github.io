About the Project

Play as the Muffin Man's monster in a retro beat-em-up, defeating other cursed pastries. Built in 15 days for NESJam 2026 (theme: Horrible night to have a curse)

I was part of the programming team with 3 other programmers. My main role within this team was coding the UI, most of the in-game cutscenes, the prologue level, the dialogue sequences, the title/credits screens and the opening sequence

Technical Highlights

  • Used a smaller version of Akoya's node-based system for composable sequences when making cutscenes, where each sequence was a list of behavior nodes ran sequentially
  • The dialogue system was data-driven, with a textbox component that took dialogue data such as the voice audio to play and the list of individual dialogue pieces to run sequentially
  • Game text is able to accept wildcard text to replace depending on different conditions. For example, controls text would automatically change depending on the device used

Features

  • Fight through the streets at night, defeating the Muffin Man's cursed pastries
  • Use punches and combos, as well as the blueberry projectile powerup
  • Retro-styled cinematic experience in the opening and ending scenes

What I Learned

Implementing the dialogue system taught me about the challenges in integrating sound with moving text, as well as timing the two together. The resulting system made in the jam period definitely has room for improvement, but it is a solid start that worked well in the final product.

Re-using the architectural form of Akoya's node based system for cutscene exposed a weakness in it: since it has to use scene nodes, it can be prone to usability issues when including references to things outside the root of the sequence. This can be mitigated with more careful scene architecture or by transforming the system into a truly data-driven one where all the configuration lives on a single object
